# GOX FIRST-DOLLAR SYNOPSIS

## What we are doing
GOX is being narrowed to a minimum viable money machine before broader expansion. The system will find legitimate already-available paying work, verify eligibility and platform rules, compile the correct canonical prompt, run an identical-agent ensemble, synthesize and QA the result, pause only for an unavoidable owner gate, submit, record economics, and immediately repeat.

## What is already in place
- no-loss first-dollar Paper Stack
- canonical first-dollar Easy Prompt
- Easy Jobs first-dollar lane and scorecard
- execution bridge
- Remote Steward service design
- browser team and persistent-session browser stack
- owner approval bridge core
- voice-control approval prototype
- continuity/source-of-truth documents

## What still blocks money
1. independently verify steward write-back by reading result files
2. independently verify a real 3-agent runtime run from steward evidence
3. connect current task-source discovery to the Easy Jobs scorecard
4. select one legitimate ready-to-work source where the assigned human lane is eligible
5. complete the first real task with full evidence
6. record first net dollar and immediately repeat

## What does NOT get to block first dollar
- GOX City expansion
- chemistry lab expansion
- Creative University expansion
- full cyber division
- broad multi-user product work
- cosmetic dashboard work

These remain preserved in the larger Paper Stack but stay behind the revenue gate.

## Owner experience target
Ron should be able to operate GOX primarily by voice. Routine coding, VPS work, testing, repair, state management, and task execution belong to the system. Owner interruption should be limited to login, MFA, CAPTCHA, identity confirmation, sensitive permissions, payment, or genuinely consequential/final approval.

## First-dollar finish line
A payout greater than zero is verified and entered into the ledger with source, task ID, gross pay, fees, net pay, owner minutes, compute cost, effective dollars per owner-hour, evidence, and the next canonical prompt.
