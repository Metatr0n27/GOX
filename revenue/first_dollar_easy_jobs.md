# GOX FIRST-DOLLAR EASY JOBS LANE

## PRIME DIRECTIVE
Optimize for verified dollars collected per unit of owner effort. Agent count is not a success metric.

## ACCEPTABLE FIRST-DOLLAR WORK
- hourly task queues already open to eligible workers
- piece-rate or per-item paid work
- data labeling / AI evaluation where rules permit assistance
- transcript/document cleanup
- spreadsheet/CSV cleanup
- public-web research and contact/data normalization where platform rules permit
- bounded extraction/classification tasks
- other legitimate available work a person could reasonably sit down and perform without first winning a bespoke client contract

## NOT AN EASY JOB FOR FIRST-PILOT PURPOSES
- speculative proposals that require a client to choose us before work can begin
- jobs with unknown payment legitimacy
- queues with no current task visibility after onboarding
- roles requiring fabricated credentials or expertise
- any task whose rules prohibit the assistance GOX would provide
- account sharing, identity borrowing, or cross-family impersonation

## SECONDARY LANE
Freelance/contract marketplaces remain useful, but proposals are secondary to available paying task queues for the first-dollar objective.

## QUALIFICATION GATE
Every candidate must pass:
- payment legitimacy
- worker eligibility
- platform terms/automation policy
- correct account identity
- task is actually available now
- payout method can be used by the assigned lane
- GOX capability fit is verified, not invented
- expected owner effort is measured
- no prohibited credential sharing or impersonation

## SCORECARD
Score 0-5 each:
- available now
- payout certainty
- expected net dollars
- repeatability
- GOX assistance fit
- low owner minutes
- low rejection risk
- low policy risk

Payout latency is tracked but is not a rejection reason by itself. A 39-day payout can still beat a fast-paying task if it is easier, more certain, or more repeatable.

Reject any task with unclear payment legitimacy or prohibited automation regardless of score.

## CURRENT PILOT ORDER
1. **Clickworker regular jobs** — primary first-dollar source after truthful owner onboarding. Prefer tasks that are visibly available, priced before starting, and whose instructions permit the planned assistance.
2. **UHRS through Clickworker** — secondary source after required assessment/payment setup. Longer payable delay is acceptable for the pilot if the work is legitimate and accepted.
3. **Next qualified microtask/task queue** — immediate fallback if Clickworker has no suitable live work or platform rules make GOX assistance unusable.

## EXECUTION LOOP
AVAILABLE TASK -> qualify -> reserve/accept if platform rules allow -> compile canonical Easy Prompt -> independent-agent ensemble when assistance is permitted -> synthesize -> execute -> QA -> owner gate only if required -> submit -> capture evidence -> record economics -> repeat.

## FIRST TARGET CLASSES
1. CSV/spreadsheet normalization and cleanup
2. document/transcript cleanup
3. public web research / structured extraction
4. AI-output evaluation / annotation when platform rules allow
5. tagging/classification queues

## EVIDENCE PACK
For every attempt record:
- source/platform
- task identifier
- assigned identity/lane
- terms/policy check result
- start/end timestamps
- raw input hash or source reference
- agent prompt ID
- outputs and QA result where storage is permitted
- owner actions/minutes
- submission evidence
- payout status
- gross/fees/net
- failure/rejection reason if any

Do not copy confidential task content into public repositories or logs. Use hashes, IDs, timestamps, and economics when task data is restricted.

## FAMILY LANE RULE
Each family member remains a separate identity/account/session/eligibility lane. Shared prompts, tools, and lessons may be reused only where platform rules permit. Never merge identities or secretly share accounts.

## FIRST-DOLLAR SUCCESS CONDITION
At least one legitimate task is completed and accepted/paid, with net revenue > $0 and the full evidence/economics record written to the ledger.
